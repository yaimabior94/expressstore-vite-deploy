# ExpressStore - Express + Vite Project

ExpressStore is a simple, clean, and production-ready Express backend with a 
Vite frontend.
This project demonstrates best practices in project structure, API design, documentation, and deployment.

---

## Features
- Express.js backend (REST API)
- Vite frontend (client)
- Clean API routes & controllers
- Ready for deployment (Render, Vercel, Railway)
- Jest + Supertest API testing
- Organized folder structure
- TypeScript-ready (if needed)
